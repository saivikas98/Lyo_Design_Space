# Freeze-Drying Design-Space Streamlit App

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The app normally opens at `http://localhost:8501`.

## Features
- Ts-based and Tp-based tie-line families
- Selectable dry-layer level
- Collapse-temperature constrained optimal trajectory
- Combined dashboard and detailed plots
- Failure counts for root-solver cases
- CSV and Excel downloads
